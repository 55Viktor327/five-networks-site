ТЕХНИЧЕСКОЕ ЗАДАНИЕ

Сайт телеком-подрядчика ООО «Пять сетей»
Тип: Pet-проект (портфолио + прокачка навыков)
Дата: финальная версия
Статус: согласовано

1. О компании (контекст)
ООО «Пять сетей» — подрядная организация в сфере связи. Направления деятельности:
- Прокладка ВОЛС — подвес, траншея, ГНБ, ввод в здание, сварка оптики, рефлектометрия.
- Монтаж и настройка сетевого оборудования — коммутаторы, маршрутизаторы, мультиплексоры, кроссы, СКС.
- Ввод в эксплуатацию локальных сетей на объектах заказчика.
- Техническое и профилактическое обслуживание объектов связи ПАО МТС — ключевое направление, компания является подрядчиком МТС.
- Установка и первичная настройка WiFi-мостов (point-to-point, point-to-multipoint).
- Строительство радиорелейных линий (РРЛ) — «последняя миля».
Сайт — B2B-имиджевый + лидогенерация. Абонентов, тарифов и личных кабинетов физлиц нет.

9. Безопасность
Публичка: сессии, CSRF-токены на формах, honeypot, rate limit на формы.
Админка: JWT (access + refresh), httpOnly cookie для refresh, rotation, blacklist в Redis.
Rate limiting: Bucket4j на /api/auth/login (5 попыток / 15 мин), на формы заявок.
Пароли: BCrypt.
CORS: настроен только для домена админки.
Заголовки: CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy.
Валидация: Jakarta Bean Validation на DTO, проверка файлов (MIME + размер).
Аудит: audit_log для действий менеджеров/админов.
2FA (опционально): TOTP через dev.samstevens.totp.

10. Нефункциональные требования
Архитектура: слоистая (Controller → Service → Repository), DTO-маппинг через MapStruct.
Обработка ошибок: глобальный @RestControllerAdvice + @ControllerAdvice для Thymeleaf.
Логирование: SLF4J + Logback, разные уровни для dev/prod.
Тесты: JUnit 5, Mockito, Testcontainers (Postgres), WireMock (интеграции).
Документация: SpringDoc OpenAPI на /swagger-ui.
Миграции: Flyway, все изменения схемы — через версионные скрипты.
Профили: dev (H2 или локальный Postgres, LocalStorage, без Redis), prod (Postgres, Redis, MinIO).
Docker: docker-compose up поднимает всё: Postgres, Redis, MinIO, backend, admin SPA.
SEO (публичка): slug'и, мета-теги, Open Graph, sitemap.xml, robots.txt, 404.
Производительность: кэш каталога услуг/проектов (@Cacheable + Redis опционально), lazy-loading изображений.

11. Дорожная карта

Этап 1. Каркас (1–2 недели)
Spring Boot проект, монорепо, .gitignore, README.
PostgreSQL + Flyway, базовые сущности (user, site_settings).
Docker Compose: Postgres.
Spring Security: две цепочки фильтров, JWT-каркас.

Этап 2. Публичная часть (2–3 недели)
Thymeleaf + Layout Dialect, базовый лейаут, стили (Tailwind или Bootstrap).
Разделы: главная, услуги, о компании, контакты.
Проекты (список + карточка, nda_level).
Новости (лента + карточка).
Вакансии (список + карточка).
Формы заявок + валидация + honeypot.

Этап 3. Хранилище файлов (1 неделя)
StorageService + LocalStorageService (dev).

Таблица stored_file, контроллер отдачи, presigned URL.
Загрузка вложений к заявкам, резюме, галерей проектов.

CRUD: услуги, проекты, новости, вакансии, справочники.
