# Five Networks — сайт ООО «Пять сетей»

B2B-сайт подрядчика в сфере связи: прокладка ВОЛС, монтаж и настройка
сетевого оборудования, обслуживание объектов связи ПАО МТС,
WiFi-мосты, строительство РРЛ.

## Стек

- **Backend:** Java 25, Spring Boot 4, Thymeleaf (публичка), REST (админка),
  Spring Security + JWT, Spring Data JPA, PostgreSQL, Flyway.
- **Admin SPA:** React + TypeScript + Vite + Ant Design (позже).
- **Инфраструктура:** Docker, docker-compose (позже).

## Структура репозитория

- `backend/` — Spring Boot приложение.
- `admin-frontend/` — SPA-админка (React).
- `docs/` — ТЗ и проектная документация.
